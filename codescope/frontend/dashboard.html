WHY LoRA?
LoRA (Low-Rank Adaptation) freezes the pre-trained weights and injects trainable rank-decomposition matrices into each attention layer. With r=8, we only update 0.08% of parameters — making fine-tuning feasible on a free GPU in under 15 minutes, while adapting the model to answer CodeScope-specific Q&A patterns more precisely than the base model.

Input Guardrail — Topic Filter
Rejects questions referencing technologies not present in the indexed codebase (Redis, Kafka, PyTorch, XGBoost, etc.) before the LLM is even called. Prevents off-topic hallucinations at the source.
Output Guardrail — Reference Checker
Scans the LLM's answer for .py file references or library names not found in the indexed chunks. If unknown references appear, the answer is flagged and replaced with a safe fallback.
